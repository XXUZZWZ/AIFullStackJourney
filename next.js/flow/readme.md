## 低代码 Agent 开发框架 ReactFlow

- React Flow 是一个流行的 React 库，用于构建交互式的、基于节点的图表和工作流（如流程图、数据管道和图形编辑器），支持拖拽、缩放以及自定义节点和边等特性。
- 基于 canvas 技术
- node 节点 llm 插件 ...
- edge 边 节点的顺序
- 一个 json 存储这些 信息到后端
