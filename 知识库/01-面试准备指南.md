## ⚡ 前端基础

### JavaScript 核心 (P0 必学)

#### 🔥 执行上下文与作用域链
- **重要程度**: ⭐⭐⭐ 高频
- **知识点**: 执行上下文、变量环境、作用域链、词法作用域
- **代码位置**:
  - `javaScript/scope_closure/` - 作用域与闭包完整讲解

- **面试常问**:
  - "解释 JavaScript 的作用域"
  - "什么是执行上下文"
  - "作用域链如何工作"

#### 🔥 闭包原理与应用
- **重要程度**: ⭐⭐⭐ 高频必考
- **知识点**: 闭包定义、形成原理、应用场景、内存泄漏
- **代码位置**:
  - `javaScript/closure/` - 闭包基础
  - `javaScript/closure_example/` - 闭包示例
  - `interview/js/` - 面试闭包题
  - `javaScript/scope_closure/从C++看JavaScript闭包.md` - 深入讲解
- **学习建议**:
  - P0: 理解闭包的本质（函数 + 词法环境）
  - P1: 掌握闭包的常见应用（防抖、节流、模块模式）
  - P2: 了解闭包与内存管理
- **常见题目**:
  - 变量作用域陷阱（var/let/const 循环问题）
  - 函数工厂模式
  - 柯里化实现

#### 🔥 原型与原型链
- **重要程度**: ⭐⭐⭐ 高频必考
- **知识点**: prototype、__proto__、原型链、继承
- **代码位置**:

#### 🔥 事件循环 (Event Loop)
- **重要程度**: ⭐⭐⭐ 高频必考
- **知识点**: 微任务、宏任务、事件循环、执行顺序
- **代码位置**:

  - 理解 Call Stack、Task Queue、Microtask Queue
  - 掌握 setTimeout、Promise、async/await 的执行顺序
  - 会手写复杂的事件循环题目
- **常见题目**:
  - 复杂的 setTimeout + Promise 顺序题

#### 🔥 this 指向问题
- **重要程度**: ⭐⭐⭐ 高频必考
