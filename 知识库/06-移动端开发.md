## 🚀 React Native 基础

### 🔥 React Native 概述

#### 核心理念
- **一次编写，多平台运行**: 用 JavaScript 开发 iOS 和 Android
- **原生性能**: 编译为原生代码，性能接近原生应用
- **React 思维**: 使用 React 的组件化开发方式

#### 工作原理
```
React Components
      ↓
React Native Bridge
      ↓
Native Code (Objective-C/Java)
      ↓
iOS/Android 应用
```

#### 学习路线
1. **第一周**: 基础组件、样式、布局
2. **第二周**: 路由、状态管理、网络请求
3. **第三周**: 原生模块、性能优化
4. **第四周**: 打包发布、应用上架

#### 代码位置
- `react-native/my-react-native-app/` - 基础应用
- `react-native/my-new-app/` - 进阶应用
- `react-native/readme.md` - 详细指南

### 🔥 Expo vs 裸应用 (Bare React Native)

#### Expo 方式
- **优势**:
  - 快速开发，无需编译原生代码
  - OTA 更新（Over-The-Air）
  - 内置许多常用 API
  - 直接在手机上预览（Expo Go）
- **劣势**:
  - 依赖 Expo 生态
  - 某些原生功能不支持
  - 包体积较大
- **适用**: 快速原型、学习、中等复杂度应用

#### 裸应用 (Bare Workflow)
- **优势**:
  - 完全控制原生代码
  - 支持所有原生 API
  - 包体积更小
  - 灵活性最高
- **劣势**:
  - 需要配置原生开发环境
  - 学习曲线陡峭
  - 维护复杂
- **适用**: 复杂应用、高性能需求、特殊需求

#### 选择建议
```
学习阶段 → Expo
快速原型 → Expo
生产应用 → 评估复杂度
  ├─ 简单 → Expo
  └─ 复杂 → 裸应用
```

## 🎨 核心组件

### 🔥 基础组件

#### View - 容器组件
```javascript
import { View } from 'react-native';

// 类似 HTML 的 div
<View style={{ flex: 1, backgroundColor: '#f0f0f0' }}>
  {/* 内容 */}
</View>
```

#### Text - 文本组件
```javascript
import { Text } from 'react-native';

// 所有文本必须包装在 Text 组件中
<Text style={{ fontSize: 16, color: '#333' }}>
  Hello, React Native!
</Text>
```

#### Image - 图片组件
```javascript
import { Image } from 'react-native';

// 必须指定宽高
<Image
  source={{ uri: 'https://example.com/image.png' }}
  style={{ width: 200, height: 200 }}
/>

// 本地图片
<Image
  source={require('./assets/logo.png')}
  style={{ width: 200, height: 200 }}
/>
```

#### ScrollView - 滚动容器
```javascript
import { ScrollView } from 'react-native';

<ScrollView style={{ flex: 1 }}>
  {/* 可滚动内容 */}
</ScrollView>
```

#### FlatList - 列表组件（重要）
```javascript
import { FlatList } from 'react-native';

<FlatList
  data={[
    { id: '1', title: 'Item 1' },
    { id: '2', title: 'Item 2' },
  ]}
  renderItem={({ item }) => <Text>{item.title}</Text>}
  keyExtractor={item => item.id}
  onEndReached={loadMore} // 分页加载
  onEndReachedThreshold={0.1}
/>
```

### 🔥 交互组件

#### TouchableOpacity - 可点击容器
```javascript
import { TouchableOpacity } from 'react-native';

<TouchableOpacity onPress={() => alert('Pressed!')}>
  <Text>Press me</Text>
</TouchableOpacity>
```

#### TextInput - 输入框
```javascript
import { TextInput } from 'react-native';

<TextInput
  placeholder="Enter text"
  value={text}
  onChangeText={setText}
  style={{ borderBottomWidth: 1, padding: 10 }}
/>
```

#### Switch - 开关
```javascript
import { Switch } from 'react-native';

<Switch
  value={isEnabled}
  onValueChange={setIsEnabled}
/>
```

#### Picker - 选择器
```javascript
import { Picker } from '@react-native-picker/picker';

<Picker
  selectedValue={selected}
  onValueChange={setSelected}
>
  <Picker.Item label="Option 1" value="opt1" />
  <Picker.Item label="Option 2" value="opt2" />
</Picker>
```

#### Modal - 模态框
```javascript
import { Modal } from 'react-native';

<Modal
  visible={isVisible}
  transparent={true}
  animationType="slide"
  onRequestClose={() => setIsVisible(false)}
>
  {/* 模态内容 */}
</Modal>
```

## 🎨 样式与布局

### 🔥 React Native 样式系统

#### 不同于 CSS 的地方
- **没有级联**: 样式不继承
- **没有单位**: 默认单位是 dp（设备无关像素）
- **Flexbox 布局**: 默认 `flex: 1`
- **驼峰命名**: `backgroundColor` 而不是 `background-color`

#### 样式定义方式
```javascript
import { StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  container: {
    flex: 1,
    padding: 16,
    backgroundColor: '#fff',
  },
  text: {
    fontSize: 16,
    color: '#333',
    fontWeight: 'bold',
  }
});

// 使用
<Text style={styles.text}>Hello</Text>

// 组合样式
<View style={[styles.container, { backgroundColor: '#f0f0f0' }]}>
  {/* 内容 */}
</View>
```

### 🔥 Flexbox 布局

#### 主要属性
```javascript
{
  // 主轴方向（默认 column）
  flexDirection: 'row', // 'row' | 'column' | 'row-reverse'

  // 主轴对齐
  justifyContent: 'center', // 'flex-start' | 'center' | 'space-between'

  // 交叉轴对齐
  alignItems: 'center', // 'flex-start' | 'center' | 'stretch'

  // 子元素伸缩
  flex: 1,

  // 内边距
  padding: 16,
  paddingHorizontal: 10,
  paddingVertical: 20,

  // 外边距
  margin: 10,
  marginTop: 20,
}
```

#### 常见布局模式
```javascript
// 水平居中垂直居中
{
  flex: 1,
  justifyContent: 'center',
  alignItems: 'center',
}

// 左右布局（两列）
{
  flexDirection: 'row',
  justifyContent: 'space-between',
}

// 自适应列表（两列网格）
{
  flexDirection: 'row',
  flexWrap: 'wrap',
}
```

### 📌 响应式设计

#### 适配不同屏幕
```javascript
import { Dimensions } from 'react-native';

const { width, height } = Dimensions.get('window');

const styles = StyleSheet.create({
  container: {
    width: width > 600 ? '50%' : '100%',
  }
});
```

## 🔄 状态管理

### 🔥 Redux 或 Context

#### 使用 Redux
```bash
npm install redux react-redux
npm install -D @redux-devtools/core
```

```javascript
import { useDispatch, useSelector } from 'react-redux';

function App() {
  const count = useSelector(state => state.counter.count);
  const dispatch = useDispatch();

  return (
    <TouchableOpacity onPress={() => dispatch(increment())}>
      <Text>{count}</Text>
    </TouchableOpacity>
  );
}
```

#### 使用 Zustand
```bash
npm install zustand
```

```javascript
import create from 'zustand';

const useStore = create(set => ({
  count: 0,
  increment: () => set(state => ({ count: state.count + 1 })),
}));

function App() {
  const { count, increment } = useStore();

  return (
    <TouchableOpacity onPress={increment}>
      <Text>{count}</Text>
    </TouchableOpacity>
  );
}
```

### 📌 异步存储（AsyncStorage）

#### 类似 localStorage 的本地存储
```javascript
import AsyncStorage from '@react-native-async-storage/async-storage';

// 保存数据
await AsyncStorage.setItem('key', 'value');

// 读取数据
const value = await AsyncStorage.getItem('key');

// 删除数据
await AsyncStorage.removeItem('key');

// 清空所有
await AsyncStorage.clear();
```

## 🌐 网络请求

### 🔥 Fetch API

#### 基本用法
```javascript
// GET 请求
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error(error));

// POST 请求
fetch('https://api.example.com/data', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ name: 'John' }),
})
  .then(response => response.json())
  .then(data => console.log(data));
```

### 📌 Axios (可选)

```bash
npm install axios
```

```javascript
import axios from 'axios';

axios.get('https://api.example.com/data')
  .then(response => console.log(response.data))
  .catch(error => console.error(error));

// 拦截器
axios.interceptors.request.use(config => {
  config.headers.Authorization = `Bearer ${token}`;
  return config;
});
```

## 🔗 原生模块集成

### 🔥 常用 Expo API

#### 相机
```javascript
import * as ImagePicker from 'expo-image-picker';

const result = await ImagePicker.launchCameraAsync({
  aspect: [4, 3],
  quality: 1,
});

if (!result.cancelled) {
  console.log(result.uri);
}
```

#### 地理位置
```javascript
import * as Location from 'expo-location';

const location = await Location.getCurrentPositionAsync({});
console.log(location.coords);
```

#### 本地通知
```javascript
import * as Notifications from 'expo-notifications';

await Notifications.scheduleNotificationAsync({
  content: {
    title: 'Hello!',
    body: 'This is a notification',
  },
  trigger: { seconds: 2 },
});
```

#### 文件系统
```javascript
import * as FileSystem from 'expo-file-system';

// 读取文件
const content = await FileSystem.readAsStringAsync(
  FileSystem.documentDirectory + 'file.txt'
);

// 写入文件
await FileSystem.writeAsStringAsync(
  FileSystem.documentDirectory + 'file.txt',
  content
);
```

### 📌 权限申请

```javascript
import * as Permissions from 'expo-permissions';

// 申请相机权限
const { status } = await Permissions.askAsync(
  Permissions.CAMERA
);

if (status !== 'granted') {
  alert('权限被拒绝');
}
```

## ⚡ 性能优化

### 🔥 常见性能问题

#### 1. FlatList 性能优化
```javascript
<FlatList
  data={items}
  renderItem={renderItem}
  keyExtractor={item => item.id}
  // 重要配置
  removeClippedSubviews={true}
  initialNumToRender={10}
  maxToRenderPerBatch={10}
  updateCellsBatchingPeriod={50}
  windowSize={10}
/>
```

#### 2. 减少重新渲染
```javascript
// 使用 React.memo
const Item = React.memo(({ item }) => (
  <Text>{item.title}</Text>
));

// 使用 useCallback
const renderItem = useCallback(({ item }) => (
  <Item item={item} />
), []);
```

#### 3. 图片优化
```javascript
<Image
  source={{ uri: 'https://example.com/image.jpg' }}
  style={{ width: 200, height: 200 }}
  // 重要：提前设置宽高
  resizeMode="contain"
  // 预加载
  progressiveRenderingEnabled={true}
/>
```

## 💡 最佳实践

### 开发建议
1. **从 Expo 开始**: 快速学习，降低门槛
2. **优先使用官方 API**: Expo 库覆盖 90% 需求
3. **性能优先**: 移动端性能比 Web 更关键
4. **充分测试**: 真机测试不能省
5. **渐进式升级**: 逐步升级到复杂功能

### 避免的陷阱
- ❌ 不要在主线程做长时间计算
- ❌ 不要频繁更新 FlatList 的 data 引用
- ❌ 不要忽视内存泄漏
- ❌ 不要过度使用动画
- ❌ 不要在渲染函数中创建新对象
