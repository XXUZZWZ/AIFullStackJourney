## 🧠 LLM 基础概念

### 🔥 LLM 的核心特性

#### 无状态性
- **含义**: LLM 本身没有状态，每次请求都是独立的
- **影响**: 需要通过历史消息维护对话上下文
- **代码位置**: `interview/ai/history/` - 上下文管理详解
- **解决方案**:
  - 消息数组管理（message history）
  - Token 计数与限制
  - 滑动窗口策略
  - 上下文压缩

#### Token 与成本
- **Token 定义**: 文本单位，1 个单词约 1.3 个 token
- **计费基础**: 按 input/output token 计费
- **优化策略**:
  - 精简 prompt
  - 压缩上下文
  - 使用缓存
  - 批量请求
- **计算工具**: OpenAI Tokenizer 在线工具

#### 模型版本
- **Latest Model**: 最新版本，更聪明但更贵
- **Stable Model**: 稳定版本，性价比好
- **选择建议**: 开发用稳定版，生产用最新版

## 🔑 OpenAI API 集成

### 🔥 基础 API 使用

#### 安装与初始化
```javascript
import OpenAI from 'openai';

const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});
```

#### 基本聊天完成
```javascript
const response = await openai.chat.completions.create({
  model: "gpt-4",
  messages: [
    { role: "system", content: "你是一个有帮助的助手" },
    { role: "user", content: "你好" }
  ],
  temperature: 0.7,
  max_tokens: 2000,
});

console.log(response.choices[0].message.content);
```

#### 重要参数解析
- **model**: 选择模型版本
- **temperature** (0-2):
  - 0: 确定性回复（总是相同答案）
  - 0.7: 平衡创意与一致性
  - 2: 最具创意
- **top_p** (0-1): 核心采样，控制多样性
- **max_tokens**: 最大输出长度
- **presence_penalty** (-2 到 2): 重复主题惩罚
- **frequency_penalty** (-2 到 2): 词频惩罚

```javascript
function trimMessages(messages, maxTokens = 4000) {
  let totalTokens = 0;
  const trimmed = [];

  // 从后向前累加消息
  for (let i = messages.length - 1; i >= 0; i--) {
    const tokens = encoding.encode(messages[i].content).length;
    if (totalTokens + tokens > maxTokens) break;
    trimmed.unshift(messages[i]);
    totalTokens += tokens;
  }

  return trimmed;
}
```

### 🔥 错误处理与重试

#### 常见错误
- **401 Unauthorized**: API key 无效
- **429 Too Many Requests**: 超出配额
- **500 Server Error**: 服务器错误

#### 重试策略
```javascript
async function retryWithBackoff(fn, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn();
    } catch (error) {
      if (error.status === 429 || error.status >= 500) {
        const delay = Math.pow(2, i) * 1000; // 指数退避
        await new Promise(resolve => setTimeout(resolve, delay));
      } else {
        throw error;
      }
    }
  }
}
```

## 📚 RAG 系统 (检索增强生成)

### 🔥 RAG 的核心原理

#### 工作流程
1. **文本分块**: 将大文档分解为小块
2. **向量化**: 使用 embedding 模型将文本转为向量
3. **存储**: 将向量存储到向量数据库
4. **检索**: 用户查询时，先将查询向量化，然后在数据库中查找相似向量
5. **增强**: 将检索到的文本作为上下文，与用户查询一起发送给 LLM
6. **生成**: LLM 基于上下文生成答案

#### 优势
- **准确性**: 使用真实数据而非 LLM 的先验知识
- **实时性**: 支持最新信息
- **成本**: 减少 token 使用（通过精准检索）
- **可控性**: 可以审查和更新知识库

### 实现细节

#### 1. 文本分块策略
```javascript
function chunkText(text, chunkSize = 500, overlap = 100) {
  const chunks = [];
  for (let i = 0; i < text.length; i += chunkSize - overlap) {
    chunks.push(text.slice(i, i + chunkSize));
  }
  return chunks;
}
```

#### 2. 向量化
```javascript
async function getEmbedding(text) {
  const response = await openai.embeddings.create({
    model: "text-embedding-3-small",
    input: text,
  });
  return response.data[0].embedding;
}
```

#### 3. 相似度搜索
```javascript
function cosineSimilarity(a, b) {
  const dotProduct = a.reduce((sum, x, i) => sum + x * b[i], 0);
  const magnitudeA = Math.sqrt(a.reduce((sum, x) => sum + x * x, 0));
  const magnitudeB = Math.sqrt(b.reduce((sum, x) => sum + x * x, 0));
  return dotProduct / (magnitudeA * magnitudeB);
}
```

#### 4. 完整 RAG 查询
```javascript
async function ragQuery(userQuery, documents) {
  // 向量化查询
  const queryVector = await getEmbedding(userQuery);

  // 查找相似文档
  const similarDocs = documents
    .map(doc => ({
      content: doc,
      similarity: cosineSimilarity(queryVector, doc.vector)
    }))
    .sort((a, b) => b.similarity - a.similarity)
    .slice(0, 3);

  // 构建上下文
  const context = similarDocs
    .map(doc => doc.content)
    .join("\n\n");

  // 调用 LLM
  const response = await openai.chat.completions.create({
    model: "gpt-4",
    messages: [
      {
        role: "system",
        content: `你是一个有用的助手。使用以下信息回答用户的问题：\n${context}`
      },
      {
        role: "user",
        content: userQuery
      }
    ]
  });

  return response.choices[0].message.content;
}
```

```javascript
class PromptTemplate {
  constructor(template, inputVariables) {
    this.template = template;
    this.inputVariables = inputVariables;

  format(variables) {

    for (const [key, value] of Object.entries(variables)) {

    return result;

}
```

## 🤖 Agent 系统

### 🔥 Agent 的核心概念

#### 定义
- **Agent**: 能够自主决策和采取行动的 AI 系统
- **循环**: 观察 → 思考 → 行动 → 观察...
- **工具**: Agent 可以调用外部工具完成任务

#### 架构
```
用户输入
   ↓
[LLM 思考]
   ↓
[判断是否需要工具]
   ↓
[如需要] → [调用工具] → [获取结果]
   ↓        [返回结果] ↓
[继续思考] ← ← ← ← ← ←
   ↓
[生成最终答案]
   ↓
用户输出
```

### 实现示例

#### 简单 Agent 实现
```javascript
async function runAgent(userQuery) {
  const messages = [
    {
      role: "system",
      content: `你是一个能够使用工具的 AI 助手。
你可以使用以下工具：${JSON.stringify(tools.map(t => t.name))}`
    },
    { role: "user", content: userQuery }
  ];

  while (true) {
    const response = await openai.chat.completions.create({
      model: "gpt-4",
      messages,
      tools: tools.map(tool => ({
        type: "function",
        function: tool
      })),
      tool_choice: "auto"
    });

    if (!response.choices[0].message.tool_calls) {
      // 没有工具调用，返回最终答案
      return response.choices[0].message.content;
    }

    // 处理工具调用
    for (const toolCall of response.choices[0].message.tool_calls) {
      const result = await executeFunction(
        toolCall.function.name,
        JSON.parse(toolCall.function.arguments)
      );

      messages.push(response.choices[0].message);
      messages.push({
        role: "user",
        content: [{
          type: "tool_result",
          tool_use_id: toolCall.id,
          content: JSON.stringify(result)
        }]
      });
    }
  }
}
```

```javascript
      // 限流，使用较便宜的模型重试
      return await openai.chat.completions.create({
        model: "gpt-3.5-turbo",
        messages
      });
    }
    throw error;
  }
}
```

#### 2. 成本追踪
```javascript
function calculateCost(tokens, model) {
  const rates = {
    "gpt-4": { input: 0.03, output: 0.06 },
    "gpt-3.5-turbo": { input: 0.0005, output: 0.0015 }
  };

  const rate = rates[model];
  const inputCost = tokens.prompt_tokens * rate.input / 1000;
  const outputCost = tokens.completion_tokens * rate.output / 1000;

  return inputCost + outputCost;
}
```
