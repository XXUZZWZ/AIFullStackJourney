## 二、判断题

### 1. RAG 系统需要重新训练大语言模型才能更新知识库。

**答案：错误**  
**解析：RAG 的优势就是无需重新训练模型，只需更新知识库即可。**

### 2. 向量相似度是 RAG 系统中检索相关文档的主要方法。

**答案：正确**  
**解析：RAG 通过计算查询向量与文档向量的相似度来检索相关文档。**

### 3. RAG 只能处理文本数据，不能处理图像或音频。

**答案：错误**  
**解析：多模态 RAG 可以处理图像、音频等多种数据类型。**

### 4. Chunk 大小对 RAG 系统的性能没有影响。

**答案：错误**  
**解析：Chunk 大小直接影响检索精度和生成质量，需要根据具体场景调优。**

### 5. RAG 系统可以完全消除大语言模型的幻觉问题。

**答案：错误**  
**解析：RAG 可以显著减少但不能完全消除幻觉问题。**

## 三、简答题

### 1. 请简述 RAG 的工作原理。

**参考答案：**
RAG 的工作原理包含三个主要阶段：

1. **检索阶段**：将用户查询向量化，在知识库中检索最相关的文档片段
2. **增强阶段**：将检索到的文档作为上下文信息，与原始查询结合
3. **生成阶段**：大语言模型基于查询和检索到的上下文生成最终回答

### 2. RAG 系统中向量数据库的作用是什么？

**参考答案：**
向量数据库在 RAG 系统中的作用包括：

- 存储文档的向量表示
- 提供高效的相似度检索功能
- 支持大规模向量索引和查询
- 实现实时的知识库更新和维护

### 3. 如何评估 RAG 系统的效果？

**参考答案：**
RAG 系统评估可从以下维度进行：

- **检索质量**：召回率、精确率、相关性评分
- **生成质量**：答案准确性、完整性、流畅度
- **系统性能**：响应时间、吞吐量、资源消耗
- **用户体验**：满意度调研、A/B 测试结果

### 4. 列举 RAG 系统的三个主要应用场景。

**参考答案：**

1. **企业知识问答**：内部文档查询、政策解读、技术支持
2. **客户服务**：智能客服、常见问题解答、产品咨询
3. **教育培训**：在线学习助手、课程问答、学术研究支持

### 3. 代码实现：简单 RAG 查询

**题目要求：**
使用 Python 实现一个简单的 RAG 查询函数，包括文档向量化和相似度检索。

**参考代码框架：**

```python
def rag_query(query, documents, model, top_k=3):
    """
    简单RAG查询实现
    Args:
        query: 用户查询
        documents: 文档列表
        model: 嵌入模型
        top_k: 返回top-k相关文档
    Returns:
        相关文档列表
    """
    # 1. 查询向量化
    query_embedding = model.encode(query)

    # 2. 文档向量化
    doc_embeddings = model.encode(documents)

    # 3. 计算相似度
    similarities = cosine_similarity([query_embedding], doc_embeddings)

    # 4. 返回top-k结果
    top_indices = similarities[0].argsort()[-top_k:][::-1]
    return [documents[i] for i in top_indices]
```
