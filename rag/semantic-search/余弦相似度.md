## 余弦相似度原理详解

### 1. 基本概念

余弦相似度是用来衡量两个向量在方向上相似程度的度量方法。它通过计算两个向量夹角的余弦值来判断它们的相似性。

### 2. 数学公式

余弦相似度的公式为：

```
cos(θ) = (A · B) / (|A| × |B|)
```

其中：

- `A · B` 是向量 A 和 B 的点积（内积）
- `|A|` 和 `|B|` 分别是向量 A 和 B 的模长（欧几里得范数）
- `θ` 是两个向量之间的夹角

### 3. 代码实现分析

让我逐步分析这段代码：

#### 第一步：计算点积（Dot Product）

```javascript
const dotProduct = v1.reduce((acc, curr, i) => acc + curr * v2[i], 0);
```

- 点积 = v1[0]×v2[0] + v1[1]×v2[1] + ... + v1[n]×v2[n]
- 几何意义：反映两个向量在同一方向上的投影程度

#### 第二步：计算向量长度（模长）

```javascript
const lengthV1 = Math.sqrt(v1.reduce((acc, curr) => acc + curr * curr, 0));
const lengthV2 = Math.sqrt(v2.reduce((acc, curr) => acc + curr * curr, 0));
```

- 向量长度 = √(x₁² + x₂² + ... + xₙ²)
- 这是欧几里得距离的计算方式

#### 第三步：计算余弦相似度

```javascript
const similarity = dotProduct / (lengthV1 * lengthV2);
```

- 通过除法归一化，消除向量长度的影响
- 只关注向量的方向，不关注大小

### 4. 相似度值的含义

- **1.0**：完全相同方向（完全相似）
- **0.0**：垂直方向（无相关性）
- **-1.0**：完全相反方向（完全不相似）

### 5. 在语义搜索中的应用

在 RAG（检索增强生成）系统中，余弦相似度用于：

1. **文本向量化**：将文本转换为高维向量（embedding）
2. **相似性计算**：比较查询向量与文档向量的相似度
3. **检索排序**：根据相似度分数对文档进行排序

### 6. 优势特点

- **方向敏感**：关注向量方向而非大小
- **归一化**：结果在[-1,1]范围内，便于比较
- **计算高效**：只需要点积和模长计算
- **维度无关**：适用于任意维度的向量

这种方法在自然语言处理中特别有效，因为它能够捕捉文本的语义相似性，而不受文本长度的影响。
