# RAG (Retrieval-Augmented Generation) 学习笔记

## 什么是 RAG？

RAG（检索增强生成）是一种结合了信息检索和文本生成的 AI 技术架构，通过检索相关文档来增强大语言模型的回答能力。

## 核心概念

### 1. RAG 工作原理

- **检索阶段**：根据用户查询，从知识库中检索相关文档片段
- **增强阶段**：将检索到的文档作为上下文信息
- **生成阶段**：基于原始查询和检索到的上下文生成回答

### 2. RAG 架构组件

```
用户查询 → 向量化 → 相似度检索 → 上下文增强 → LLM生成 → 最终回答
```

## 主要优势

### 1. 知识更新能力

- 无需重新训练模型即可更新知识
- 实时获取最新信息
- 降低模型维护成本

### 2. 减少幻觉问题

- 基于真实文档生成回答
- 提供可验证的信息源
- 提高回答的准确性和可信度

### 3. 领域适应性

- 可针对特定领域构建知识库
- 支持企业内部知识管理
- 个性化知识服务

## 技术实现

### 1. 向量数据库

- **Chroma**: 轻量级向量数据库
- **Pinecone**: 云端向量数据库服务
- **Weaviate**: 开源向量搜索引擎
- **FAISS**: Facebook 开源的相似性搜索库

### 2. 文档处理

- **文档切分**: 将长文档分割成小块
- **向量化**: 使用嵌入模型将文本转换为向量
- **索引构建**: 建立高效的检索索引

### 3. 检索策略

- **语义检索**: 基于向量相似度
- **关键词检索**: 传统的 BM25 算法
- **混合检索**: 结合语义和关键词检索
