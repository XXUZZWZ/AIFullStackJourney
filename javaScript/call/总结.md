# Call/Apply/Bind 知识点总结

## 一、核心概念

### 1. 三者的共同点
- 都是用来改变函数执行时的 `this` 指向
- 都是 `Function.prototype` 上的方法，所有函数都可以调用

### 2. 三者的区别

| 方法 | 参数传递方式 | 执行时机 | 返回值 |
|------|------------|---------|--------|
| call | 逐个传递参数 `fn.call(obj, arg1, arg2)` | 立即执行 | 函数执行结果 |
| apply | 数组传递参数 `fn.apply(obj, [arg1, arg2])` | 立即执行 | 函数执行结果 |
| bind | 逐个传递参数 `fn.bind(obj, arg1, arg2)` | 延迟执行 | 返回新函数 |

## 二、使用场景

### 1. Call/Apply
- **立即执行**函数并改变 this 指向
- 可以互换使用，只是参数传递方式不同
- 常用于借用方法、继承等场景

```javascript
function gretting(...args) {
  return `hello, my name is ${this.name}`;
}

const lj = { name: "雷军" };
gretting.call(lj, 18, '抚州');    // 立即执行
gretting.apply(lj, [18, '抚州']); // 立即执行
```

### 2. Bind
- **延迟执行**，返回一个绑定了 this 的新函数
- 适合用于事件处理、定时器等需要延迟执行的场景

```javascript
const fn = gretting.bind(lj, 18, '抚州');
setTimeout(() => {
  fn(); // 1秒后执行
}, 1000);
```

## 三、特殊情况处理

### 1. context 为 null/undefined
- 非严格模式：this 指向 window
- 严格模式：报错

```javascript
gretting.call(null);      // 非严格模式指向 window
gretting.call(undefined); // 非严格模式指向 window
```

### 2. 类型检查
调用 call/apply/bind 的必须是函数类型：
```javascript
if(typeof this !== "function"){
  throw new Error("this is not a function");
}
```

## 四、手写 Call 实现

### 核心思路
1. 在目标对象上临时挂载函数
2. 执行函数（此时 this 自动指向目标对象）
3. 删除临时属性，返回执行结果

### 实现代码
```javascript
Function.prototype.myCall = function(context, ...args) {
  // 1. 处理 context 为空的情况
  if(context === null || context === undefined) {
    context = window;
  }

  // 2. 类型检查
  if(typeof this !== "function") {
    throw new Error("this is not a function");
  }

  // 3. 使用 Symbol 创建唯一键，防止属性覆盖
  const fnkey = Symbol("fn");

  // 4. 在 context 上挂载函数（this 指向调用 myCall 的函数）
  context[fnkey] = this;

  // 5. 执行函数并收集结果
  const result = context[fnkey](...args);

  // 6. 删除临时属性，避免污染对象
  delete context[fnkey];

  // 7. 返回执行结果
  return result;
}
```

## 五、涉及的技术点

### 1. 原型链
- `Function.prototype` 是所有函数的原型
- 在原型上添加方法，所有函数都能访问

### 2. Rest 运算符 (...)
- `...args` 收集剩余参数为数组
- `...args` 展开数组为独立参数

### 3. Symbol
- ES6 新增的原始数据类型
- 保证属性键的唯一性，防止覆盖

### 4. JavaScript 动态性
- 对象可以动态添加/删除属性
- 函数内部的 this 指向其调用者

### 5. delete 操作符
- 删除对象上的属性
- 防止临时属性污染目标对象

## 六、手写 Bind 实现

```javascript
function bind(fn, that, ...args) {
  return function(...newArgs) {
    return fn.apply(that, [...args, ...newArgs]);
  };
}
```

### 特点
- 返回新函数，支持参数合并
- 利用闭包保存 this 和初始参数
- 执行时合并初始参数和新参数

## 七、注意事项

1. **严格模式影响**：在严格模式下，null/undefined 不会转为 window
2. **Symbol 的必要性**：防止覆盖目标对象的同名属性
3. **参数处理**：call 逐个传参，apply 数组传参
4. **执行时机**：call/apply 立即执行，bind 延迟执行
5. **返回值处理**：需要返回原函数的执行结果
