## 防抖节流

都是闭包的应用场景，减少频繁的执行。

### 防抖 debounce

某段时间内只最后执行一次，其他的都会前面的值会被覆盖
频繁触发的时间间隔< delay,执行最后最后一次

### 节流 throttle

单位时间一定只执行一次,一定执行一次
像 FPS 游戏，鼠标点击再多次，固定时间就执行一次。
减少执行次数，一段时间间隔内一定执行一次 onscroll 减少执行次数
没有必要 scroll 频率触发，可以做一个单位时间内的限制，不然我们重绘重排触发太多次，页面卡顿。

## 私有变量

### 类的封装

- 类是对象的模板
  - 封装了属性和方法 ，是一个抽象的方法。
    - 对内 private 外部访问 隐私 ， 隐藏业务的复杂性。
    - 对外 public 公开的 API 完成工作。
  - 抽象的概念
  - new 实例化 生成对象
- 函数里面返回对象，对象里含有方法（public）,属性（public）
- 其他的函数对象，变量 在返回对象上不能直接访问 private 属性，但在内部可以直接访问。
