## 防抖节流

### 防抖 debounce

某段时间内只最后执行一次，其他的都会前面的值会被覆盖

### 节流 throttle

单位时间一定只执行一次
减少执行次数，一段时间间隔内一定执行一次 onscroll 减少执行次数
没有必要 scroll 频率触发，可以做一个单位时间内的限制，不然我们重绘重排触发太多次，页面卡顿。
