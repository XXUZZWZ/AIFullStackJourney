# event loop 浏览器渲染主线程的调度机制

## 定义

理解 event loop 前要了解浏览器的进程和线程
浏览器进程：浏览器进程是浏览器的

event loop 是浏览器渲染主线程的调度机制，loop 指的是循环，在 Chrome 中会用 for(;;)开启一个永久的循环，这个循环会不断检查是否有每个任务队列中是否有任务需要执行，然后不断的执行。
核心是根据给不同的类型的任务分配不同优先级，然后依次按优先级队列处理任务。
优先级高的队列会优先全部处理，处理过程中可能又会创建新任务放到别的线程执行然后将回调函数放到新的任务队列中，这些新任务会进入新的优先级队列，然后按照新的优先级队列处理。
