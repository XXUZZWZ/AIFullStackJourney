## Git

开发中如何使用 git
先设置全局设置

- git config --global user.name "XXX"
- git config --global user.email "XXX"
- 入职有那些 git 操作

  - git clone 项目
  - 主分支 main/maser
    - 可能是线上分支，大家都在用的
  - 会开一个新分支 develop 给新功能开发
  - 创建一个新分支 git checkout -b new-branch

- 常用命令
  - git pull origin main 每天上班前的动作
  - git add git commit -m "xxx" git push origin new-branch
  - git status
  - git log --oneline 查看提交记录
  - git add . 添加所有文件 到暂存区
