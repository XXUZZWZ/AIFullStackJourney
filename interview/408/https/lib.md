### 常见应用层协议（按场景分类）

- **Web/实时通信**

  - **HTTP/1.1, HTTP/2, HTTP/3(QUIC)**: Web 基础协议（80/443）
  - **HTTPS**: HTTP+TLS 加密（443）
  - **WebSocket**: 全双工实时通信（ws:80 / wss:443）
  - **gRPC**: 基于 HTTP/2 的高性能 RPC
  - **GraphQL/REST**: 基于 HTTP 的接口风格（非独立协议）

- **域名解析**

  - **DNS**: 域名解析（53/UDP,TCP）
  - **DoT/DoH**: DNS over TLS(853) / HTTPS(443)
  - **mDNS**: 局域网服务发现（5353/UDP）

- **电子邮件**

  - **SMTP/Submission**: 发送邮件（25/587/465）
  - **POP3/POP3S**: 收取邮件（110/995）
  - **IMAP/IMAPS**: 同步邮件（143/993）
  - （SPF/DKIM/DMARC 为邮件认证机制，非传输协议）

- **文件传输/共享**

  - **FTP/FTPS**: 传统文件传输（21/990）
  - **SFTP**: 基于 SSH 的文件传输（22）
  - **TFTP**: 简单文件传输（69/UDP）
  - **SMB/CIFS**: 文件/打印共享（445）
  - **NFS**: 网络文件系统（2049）

- **远程登录/桌面**

  - **SSH**: 安全远程登录（22）
  - **Telnet**: 明文远程登录（23，已过时）
  - **RDP**: 远程桌面（3389）
  - **VNC**: 远程桌面（5900+）

- **网络管理/时间/日志**

  - **SNMP**: 网络设备管理（161/162）
  - **Syslog**: 日志传输（514/UDP/TCP）
  - **NTP**: 网络时间同步（123/UDP）
  - **DHCP**: 动态分配 IP（67/68/UDP）

- **目录/认证/计费**

  - **LDAP/LDAPS**: 目录服务（389/636）
  - **Kerberos**: 认证（88）
  - **RADIUS**: 认证/计费（1812/1813）
  - **TACACS+**: 认证/授权（49）

- **多媒体/实时音视频**

  - **SIP/SDP**: 会话建立（5060/5061）
  - **RTSP**: 流媒体控制（554）
  - （RTP/RTCP 更偏会话/传输协商层，但常与上述配合）

- **消息与物联网**

  - **MQTT**: 轻量发布订阅（1883/8883）
  - **AMQP**: 高级消息队列（5672/5671）
  - **STOMP**: 文本消息协议（61613 等）
  - **CoAP**: 物联网约束设备（5683/5684/UDP）

- **即时通讯/社交**

  - **XMPP**: 即时消息（5222/5269）
  - **IRC**: 早期即时通信（6667）

- **数据/数据库协议**

  - **MySQL**: 3306
  - **PostgreSQL**: 5432
  - **MongoDB**: 27017
  - **Redis**: 6379
  - **Memcached**: 11211

- **下载/P2P/其他**
  - **BitTorrent**: P2P 文件分发（多端口/UDP DHT 6881+）
  - **WHOIS**: 域名信息查询（43）
  - **HTTP/WebDAV**: 基于 HTTP 的文件协作（443/80）
  - **IPP**: 网络打印（631）

提示：

- 加密版本通常是在明文协议上加 TLS（如 HTTP→HTTPS，LDAP→LDAPS，POP3→POP3S）。
- 某些协议既可用 TCP 也可用 UDP，具体取决于实现与场景（如 DNS）。
