# 二叉平衡树的数据结构特点

- 树

  - 相对于链表和栈的线性结构 一种非线性结构 一种非层次化数据结构

- 二叉树

  - 递归定义： 一个根节点 左子树和右子树 每一个子树也是一颗二叉树。

- 满二叉树

  - 除了叶子节点外，每个节点都有两个节点 ，且 所有节点都在同一层。
  - 2^n - 1 个节点

- 完全二叉树

  - 所有节点
  - 看电影一样，每一排都坐满了人，最后一排也是从左边开始连续坐着中间不能有空位

- 二叉搜索树 BST Binary Search Tree

  - 对于任意节点，其左子树所有节点值小于该节点值，右子树所有节点值大于该节点值。
  - 适合高效查找，插入，删除有序数据

- 二叉平衡树

  - 基于二叉搜索树
  - 约束左右子树的高度差不能超过 1，来保持平衡的二叉树
    比如
    1
    -2
    --3
    ---4

    二叉搜索树 ，为了查询都性能提升 O(n) --> O(log n)
    此时退化为链表了
    需要平衡一下。
    左旋或右旋
``` markdown
    插入前：
          30
        /
      10
        \
          20

  先左旋（对 10）：
          30
        /
      20
      /
    10

  再右旋（对 30）：
        20
        /  \
      10    30
```
AVL 树 二叉平衡树 叶子节点的层级相差不过1
为了查询效率而来 BST 的优化
