# 环形链表检测算法题解

## 问题描述

给定一个链表的头节点 `head`，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。

## 解法一：哈希表法

### 思路
遍历链表，将每个节点存入哈希表，如果遇到重复的节点，说明有环。

### 代码实现
```javascript
function hasCycle(head) {
    const visited = new Set();
    let current = head;

    while (current !== null) {
        if (visited.has(current)) {
            return true;
        }
        visited.add(current);
        current = current.next;
    }

    return false;
}
```

### 复杂度分析
- 时间复杂度：O(n)
- 空间复杂度：O(n)

### 优缺点
- 优点：思路简单，容易理解
- 缺点：需要额外空间存储节点

## 解法二：快慢指针法（Floyd判圈算法）

### 思路
使用两个指针，一个快指针（每次走两步），一个慢指针（每次走一步）。如果链表有环，快指针最终会追上慢指针。

### 代码实现
```javascript
function hasCycle(head) {
    if (!head || !head.next) {
        return false;
    }

    let slow = head;
    let fast = head.next;

    while (slow !== fast) {
        if (!fast || !fast.next) {
            return false;
        }
        slow = slow.next;
        fast = fast.next.next;
    }

    return true;
}
```

### 复杂度分析
- 时间复杂度：O(n)
- 空间复杂度：O(1)

### 优缺点
- 优点：空间复杂度为O(1)
- 缺点：代码相对复杂

## 解法三：标记法

### 思路
遍历链表，给每个访问过的节点添加标记，如果遇到已经标记的节点，说明有环。

### 代码实现
```javascript
function hasCycle(head) {
    while (head) {
        if (head.visited) {
            return true;
        }
        head.visited = true;
        head = head.next;
    }
    return false;
}
```

### 复杂度分析
- 时间复杂度：O(n)
- 空间复杂度：O(1)（但修改了原链表）

### 优缺点
- 优点：实现简单
- 缺点：修改了原链表结构

## 解法四：破坏链表法

### 思路
遍历链表，将每个节点的next指针指向一个特殊值（如自身），如果遇到指向特殊值的节点，说明有环。

### 代码实现
```javascript
function hasCycle(head) {
    const MARKER = Symbol('marker');
    let current = head;

    while (current) {
        if (current.next === MARKER) {
            return true;
        }
        const temp = current.next;
        current.next = MARKER;
        current = temp;
    }

    return false;
}
```

### 复杂度分析
- 时间复杂度：O(n)
- 空间复杂度：O(1)

### 优缺点
- 优点：空间复杂度低
- 缺点：完全破坏了链表结构

## 解法五：递归标记法

### 思路
使用递归遍历链表，通过参数传递已访问的节点集合。

### 代码实现
```javascript
function hasCycle(head, visited = new Set()) {
    if (!head) {
        return false;
    }

    if (visited.has(head)) {
        return true;
    }

    visited.add(head);
    return hasCycle(head.next, visited);
}
```

### 复杂度分析
- 时间复杂度：O(n)
- 空间复杂度：O(n)（递归栈空间）

### 优缺点
- 优点：代码简洁
- 缺点：可能栈溢出

## 性能对比

| 方法 | 时间复杂度 | 空间复杂度 | 是否修改原链表 | 适用场景 |
|------|------------|------------|----------------|----------|
| 哈希表法 | O(n) | O(n) | 否 | 通用场景 |
| 快慢指针法 | O(n) | O(1) | 否 | 最优解，面试常用 |
| 标记法 | O(n) | O(1) | 是 | 可以修改链表时 |
| 破坏链表法 | O(n) | O(1) | 是 | 不需要保留链表时 |
| 递归标记法 | O(n) | O(n) | 否 | 递归练习 |

## 实际应用场景

1. **内存管理**：检测循环引用
2. **网络拓扑**：检测网络环路
3. **状态机**：检测状态循环
4. **游戏开发**：检测无限循环

## 面试技巧

1. **优先选择快慢指针法**：这是面试官最期望看到的解法
2. **理解数学原理**：能够解释为什么快指针每次走两步
3. **考虑边界情况**：空链表、单节点、双节点等情况
4. **代码简洁性**：保持代码清晰易读

## 扩展问题

1. **找到环的入口节点**
2. **计算环的长度**
3. **断开环**
4. **检测多个环**

## 总结

环形链表检测是一个经典的算法问题，有多种解法。在实际面试中，**快慢指针法**是最推荐的解法，因为它既高效又不修改原链表结构。理解各种解法的优缺点有助于在具体场景中选择最合适的方案。
