## 贪心算法

区别程序逻辑高手和有没有算法思想的题目

- 贪心算法在每步选择中都采取最优解 不回朔，，期望得到得到全局最优解。只看眼前。

- 合并区间为啥是贪心算法

  - 因为合并区间时，按起点排序后，每当前区间和已合并的最后一个区间尝试合并
  - 这个合并就合并局部最优解，最终能得到最少的不重叠区间，符合贪心思想。

- 排序是为了贪心
  - 当前节点 <= 已合并最后一个区间的终点
