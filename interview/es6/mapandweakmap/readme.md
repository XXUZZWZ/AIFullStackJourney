# map 和 weakmap

- es6 新增的数据结构 作为企业级大型语言需要的大型内置结构

- key 可以是对象

- map 强 weakmap 弱
  - map 对象为键，对象不会被垃圾回收
  - weakmap 键为对象，对象会被垃圾回收,深拷贝。
  - 引用计数：对象引用计数，对象引用计数为 0，对象被垃圾回收
  - 标记删除：对象标记删除，对象被垃圾回收

## 垃圾回收

- 也是一套程序，也是语言底层的关键机制

- 内存的动态分配，由操作系统管理

- 引用计数：对象引用计数，对象引用计数为 0，对象被垃圾回收
- map 是强引用
- 设置 key = null map = null 来回收内存
- global.gc 负责手动垃圾回收(注意要运行 node --expose-gc xxx.js)运- Map set 要手动取消 引用
- global.gc();
