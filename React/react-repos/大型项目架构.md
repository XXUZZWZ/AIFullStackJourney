# 大型项目架构

## React 项目要考虑的几个点

1. 数据状态管理。
2. 网络请求管理
3. 路由管理
4. 页面及其需要的组件

## 对应的解决方案

1. 数据状态管理可以通过 redux 或者 react 的 context 来实现。
   这里我们以 制作一个 GlobalContext,和 GlobalProvider 来示例。
   我们创建了一个可以提供全局状态上下文的组件
   相关的 src 文件结构如下：

- context // 存放 context 文件的文件夹

  - GlobalContext.jsx // 创建全局的 GlobalContext 组件

  ```jsx
  import { createContext } from "react";
  export const GlobalContext = createContext();
  export const GlobalProvider = ({ children }) => {
    return (
      <GlobalContext.Provider value={{}}>{children}</GlobalContext.Provider>
    );
  };
  ```

- main.jsx

```jsx
// main.jsx
import { GlobalProvider } from "./context/GlobalContext";
import { createRoot } from "react-dom/client";
import App from "./App.jsx";
CreateRoot(document.getElementById("root")).render(
  <GlobalProvider>
    // 创建提供上下文的组件，App组件被当作props传入GlobalProvider组件里
    <App />
  </GlobalProvider>
);
```

2. 网络请求管理

- 创建 api 文件夹，里面存放和后端数据交互的代码，这里以 repos.js 和用 axios 库为例
  在 src 目录下封装相关的网络请求逻辑，比如：

  - api

        - repos.js

        ```js
        import axios from "axios";

        // 创建 axios 实例
        const api = axios.create({
        baseURL: "https://api.github.com/",
        timeout: 10000,
        headers: {
        'Accept': 'application/vnd.github.v3+json',
        'Content-Type': 'application/json'
        }
        });

        // 错误处理函数
        const handleError = (error) => {
        if (error.response) {
        // 服务器返回错误状态码
        console.error('API Error:', error.response.status, error.response.data);
        } else if (error.request) {
        // 请求已发出但没有响应
        console.error('No response received:', error.request);
        } else {
        // 其他错误
        console.error('Request setup error:', error.message);
        }
        throw error;
        };
        export const getRepos = async (usersName) => {
        try {
        const response = await api.get(`users/${usersName}/repos`);
        const data = await response.json();
        return data;
        } catch (error) {
        return handleError(error);
        }
        };

        ```

3. 路由管理
   在大型项目中，我们会直接把 BrowserRouter 放在 Main.jsx 中，然后把所有路由都放在 Routes.jsx 中，这样，所有的路由都会被 BrowserRouter 管理。注意一个细节，组件懒加载。

   - main.jsx

     ```jsx
     import { BrowserRouter as Router } from "react-router-dom";
     import { GlobalProvider } from "./context/GlobalContext";
     import { createRoot } from "react-dom/client";
     import "./index.css";
     import App from "./App.jsx";
     // 页面级组件由路由驱动
     createRoot(document.getElementById("root")).render(
       <GlobalProvider>
         <Router>
           <App />
         </Router>
       </GlobalProvider>
     );
     ```

     -App.jsx

     ```jsx
     import { useState, useEffect, Suspense, lazy } from "react";
     import { Routes, Route, Navigate } from "react-router-dom";
     import { Loading } from "./components/Loading";

     const RepoList = lazy(() => {
       return import("./pages/RepoList/RepoList");
     });
     function App() {
       return (
         <Suspense fallback={<Loading />}>
           <Routes>
             <Route path="/users/:id/repos" element={<RepoList />} />
             <Route path="*" element={<Navigate to="/users/XXUZZWZ/repos" />} />
           </Routes>
         </Suspense>
       );
     }
     export default App;
     ```

4. 页面及其需要的组件
   我们分别通过创建 pages,和 components 文件夹来存放页面级组件和组件级组件。
   src 目录里相关内容如下：

- components
  - Loading.jsx
  ```jsx
  export const Loading = () => {
    return (
      <div className="loading">
        <div className="loading-spinner">加载中...</div>
      </div>
    );
  };
  ```
- pages

  - ReposList

    - ReposList.jsx

    ```jsx
    const RepoList = () => {
      return <div>RepoList</div>;
    };

    export default RepoList;
    ```
